# Telegram Shop Bot

Полноценный Telegram-магазин цифровых товаров с админ-панелью, управляемой
полностью через Telegram — без изменения кода после запуска.

Стек: **aiogram 3** (async), **PostgreSQL** + **SQLAlchemy 2.0 (async)**,
**Docker Compose**.

## Возможности

- Каталог: категории → товары → покупка
- Продажа цифровых позиций (ключи/аккаунты/коды) — по одной на покупателя,
  выдаётся только после подтверждённой оплаты (Telegram Payments или Stars)
- Админ-панель (доступ только по ID из `.env`):
  - категории: добавление, переименование, описание, вкл/выкл, порядок, фото
  - товары: добавление (пошагово), название/описание/цена/категория/статус,
    фото, цифровые позиции, удаление
  - промокоды: скидка %, срок действия, лимит использований
  - статистика, последние заказы, рассылка с подтверждением
  - фото каталога, категорий и товаров — только загружаются вручную через
    Telegram, в проекте никаких готовых изображений нет
- FSM для всех пошаговых операций, с отменой на каждом шаге
- Все данные — в PostgreSQL, ничего не теряется при перезапуске
- Подтверждение перед любым удалением
- Бот не падает при ошибках ввода, БД или Telegram API — все обрабатывается
  и логируется

## Быстрый старт

1. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
   - `ADMIN_IDS` — ваш Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot))
   - `PAYMENT_PROVIDER_TOKEN` — токен платёжного провайдера от BotFather
     (Payments). Если хотите продавать за **Telegram Stars**, оставьте это
     поле пустым и укажите `CURRENCY=XTR`.

2. Запустите:

   ```bash
   docker compose up -d --build
   ```

   Бот сам создаст таблицы в базе при первом запуске.

3. Откройте бота в Telegram, отправьте `/start` (обычное меню) или `/admin`
   (админ-панель, если ваш ID указан в `ADMIN_IDS`).

## Структура проекта

```
bot/
  config.py            # настройки из .env
  main.py              # точка входа, регистрация роутеров и middleware
  middlewares.py        # сессия БД, регистрация пользователя, ловля ошибок
  database/
    models.py           # User, Category, Product, DigitalItem, Order, PromoCode, Setting
    engine.py            # async-движок, создание таблиц
    repo.py              # все операции с БД
  states/states.py       # FSM-состояния
  keyboards/              # инлайн-клавиатуры (user.py, admin.py)
  filters/admin.py         # серверная проверка прав администратора
  handlers/
    user/                  # каталог, заказы, профиль, /start
    admin/                  # категории, товары, позиции, промокоды, рассылка, статистика, настройки
    payments.py               # pre_checkout_query + successful_payment
  utils/                       # форматирование, логирование, рендер экранов
```

## Первые шаги в боте (администратор)

1. `/admin` → 📦 Товары → ➕ Добавить категорию
2. Откройте категорию → ➕ Добавить товар → название → описание → цена → фото
3. В карточке товара → 📦 Позиции → ➕ Добавить позиции → отправьте ключи,
   каждый с новой строки
4. Товар автоматически появится в каталоге для пользователей

## Платежи

Используется нативный Telegram Payments API (`send_invoice` /
`pre_checkout_query` / `successful_payment`). Цифровая позиция выдаётся
**только** после `successful_payment` и атомарной блокировки одной свободной
позиции в БД (`SELECT ... FOR UPDATE SKIP LOCKED`) — два одновременных
покупателя никогда не получат один и тот же ключ. Если позиции закончились
уже после оплаты (гонка состояний), заказ помечается `failed`, покупателю
показывается сообщение о необходимости возврата, а все администраторы
получают уведомление для ручного возврата.

## Хранилище состояний FSM

По умолчанию используется `MemoryStorage` (состояния сбрасываются при
перезапуске бота, что не критично — это только временные пошаговые формы
администратора). Для продакшена с несколькими воркерами замените на
`RedisStorage` из `aiogram.fsm.storage.redis`.

## Примечание про фотографии

Бот хранит только `file_id` от Telegram — сами файлы не скачиваются и не
хранятся на сервере. Никаких изображений в репозитории нет и не будет:
всё загружается вами через кнопки «Фото» в админ-панели.
